# 구조와 동작 규약

## 판단과 실행

| 구성 | 역할 |
|---|---|
| 장기 LLM | 게임 설명·요청·관측을 바탕으로 목표와 근거, 완료/보류 상태 관리 |
| 중기 LLM | 현재 작업·조건부 후속 작업·완료 증거·재검토 조건 수립 |
| JEV | 행동 종류를 고른 뒤 관측된 도메인에서 대상·좌표·수량 선택 |
| 대화·경험 LLM | 메시지에 응답하고 경험의 근거·반례로 지침 갱신 |
| 로컬 실행기 | Mineflayer와 경로 탐색으로 동작 수행, 물리 조건 검사·취소·결과 확인 |

JEV는 실행 중에도 유지·전환을 판단합니다. 요청 이후 실행 단계가 달라진 전환 응답은 적용하지 않고 최신 상태로 재판단합니다. 최신 판단의 중단 선택은 허용하며 채굴 유지를 강제하지 않습니다. 현재 작업·실행 시작 당시 계획·완료 기록을 구분하고, 기록·관찰과 실제 획득의 목적을 일치시키도록 모델에 안내합니다. 계획·대화 호출은 실행과 독립적으로 진행하며, 같은 역할의 중복 요청과 오래된 응답의 적용을 막습니다. 한 봇의 실제 액션은 한 실행기만 소유합니다. 낮은 신뢰도만으로 유효한 선택을 거부하지 않습니다. 기본 `direct` 방식은 행동과 모든 인자를 선택하면 추가 모델 승인 없이 실행을 시도합니다. 인자를 단계별로 승인·철회하지 않으며, 대기·유지·중지는 행동 선택에서 결정합니다. 빈 선택 범위·잘못된 응답·실행 직전 조건 변화는 실행하지 않고 기록합니다. 기존 승인 방식은 비교용 설정으로 남아 있습니다.

기본 `TARGET_POLICY=observed`에서는 LLM이 구체적인 대상 목록 대신 작업 의도를 제공합니다. JEV의 선택 범위는 사전 구현된 액션과 관측에 근거한 유한한 인자 도메인입니다. 로컬 코드는 경로 탐색·물리 검증을 수행하지만 임의의 대체 행동을 선택하지 않습니다.

## 관측과 기억

현재 시야는 방향·거리·가림을 검사합니다. 모델 지도는 현재 관측과 LLM이 지정한 중요 장소로 구성하며, 과거 일반 지형은 로컬 경로 탐색용으로만 유지합니다. 중요 장소에는 좌표·관측 시각·변경 상태가 남습니다. 서버가 제공하는 전체 지도나 상대 인벤토리·숨은 체력을 모델에게 제공하지 않습니다. 제작법 입력은 해당 봇의 서버 해금 기록을 사용하며 LLM의 사전 지식은 제한하지 않습니다.

경험·지침, 사회적 기억, 장소·보관함, 자율 목표는 봇별로 저장합니다. JEV에는 활성 경험 지침 전체를 조건·불확실성과 함께 전달합니다. LLM은 새 경험 검토와 주기적 전체 정리에서 중복을 병합하고 반례에 따라 수정·보류합니다. 새 경험이 없어도 5분마다 정리하며, 지침집이 약 6,000자를 넘으면 1분 간격으로 검토합니다. 원본 경험·근거·이전 버전은 보존하고 검증된 변경만 한 번에 적용합니다. 채팅과 오래된 관측은 확인된 현재 사실로 취급하지 않습니다. 재접속 시 목표를 현재 관측으로 재검토하며 사용자 요청·이전 작업을 그대로 재실행하지 않습니다.

현재 관측과 선택지의 공통 객체는 ID로 참조합니다. 직전 결과는 상태 변화 중심으로, 선택 피드백은 짧은 사실 문장·대상·상태·횟수로 전달합니다. 피드백은 로컬 행동 규칙이 아닙니다. JEV와 중기 LLM에는 연속된 같은 시선의 완료·관측 변화 없음, 목적지별 실패 횟수와 마지막 진단을 함께 전달합니다. 경로를 찾지 못한 경우 탐색 상태·시간 한도·끝점·높이 차·탐색 중 직접 관측한 주변 블록을 기록하며, 높이 차만으로 불가능 원인을 단정하지 않습니다. 중기 계획은 `next/then/done/blocked` 작업 지침을 기존 의도 필드에 최대6항목·항목당500자로 작성하도록 요청합니다. 이는 실행 큐나 액션 제한이 아니며, 단계의 의미·완료 여부는 모델이 판단합니다. 현재·과거 계획과 진행 중·완료된 결과를 구분하도록 지시하며 기존 원본 근거는 유지합니다. 반복은 행동 금지 조건이 아닙니다.

## 결과를 기록하는 기준

- `mine`: 관측한 블록 하나에 접근·채굴·짧은 줍기를 수행합니다. JEV는 블록과 도구를 선택하고 시간은 선택하지 않습니다. 실행기는 장착 후 블록·도구·효과·물속/공중 상태로 시간을 추정해 여유를 더합니다(최대10분, 추정 불가 시30초). 진행 입력은 단계·경과·예상 남은 시간·실행 제한이며 실제 파괴 진행률은 아닙니다. 중단은 계속 가능하며, 블록 파괴, 드롭 관측, 실제 인벤토리 획득을 구분합니다. 시간 초과는 채굴 불가능의 증거가 아닙니다.
- `look`: 좌우·위아래 각도를 함께 적용한 뒤 현재 시야를 즉시 다시 관측합니다. 같은 각도나 가림 때문에 보이는 블록이 그대로일 수 있어 모터 완료와 시야 변화는 별도로 기록합니다.
- `move`: 목적지 블록 셀의 반경2 안까지 접근합니다. 정확한 좌표에 서는 기능은 아닙니다. 이미 도착한 좌표는 관측·기억에 유지하되 새 이동 인자에서 제외합니다. 설명·선택·실행은 같은 완료 기준을 공유합니다. 목적지 기억은 경로 성공을 보장하지 않습니다.
- `give`: 아이템을 떨어뜨린 결과를 기록하며 상대 수령은 자동 확정하지 않습니다.
- 전투: 보이는 적에 대한 싸움/도주 선택은 모델이, 재접근·공격 등 실제 제어는 로컬 스킬이 처리합니다.
- 사망: 자동 리스폰 후 마지막 생존 관측과 현재 장비·위험을 바탕으로 회수 여부를 검토합니다. 사망 기록만으로 드롭이 남아 있다고 가정하지 않습니다.

## 코드 위치

`providers`·`parameter-supervisor`: 모델 호출과 선택 / `runtime`·`planning`·`goals`: 제어와 계획 / `vision`·`spatial-memory`·`experience-memory`: 관측과 기억 / `mining`·`building`·`combat` 등: 로컬 액션.
