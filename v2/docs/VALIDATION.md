## 현재 병목

**이동과 생산적인 행동.** 반경2 완료 기준을 설명·인자 선택·실행에서 통일했습니다. 최신 두 봇 서버 기능검증은 같은 시작 조건에서120초 정상 종료했고 이동32회에 성공했습니다. 이전 실행과 동일한 첫62.2초의 평균 무실행 비율은54.6%→36.3%였지만, 후반 한 봇의 시선 인자 철회가 반복되어 전체120초는56.5%였습니다. 무실행은 액션 실행 구간 외 시간이며 명시적인 `idle` 선택이나 물리적 정지와 다릅니다. 이동 취소27회와 경로 실패3회가 있었고 채집·제작·설치·전달은 없었습니다. 이동 증가가 생산적인 플레이를 입증하지는 않습니다.

**입력 크기와 기억.** 일반 지형 누적을 모델 입력에서 제외하고 관측·중요 장소·선택지를 공유 참조로 연결했습니다. 이전 한도 오류18건의 재구성 요청은 평균73.5KB→28.4KB로 줄었습니다. 후속120초 서버 실행에서 실제 JEV757회와 LLM55회가 응답했고 입력 한도 오류는0건이었습니다. JEV 입력은 중앙값12.2k·최대20.6k 토큰이었습니다. 다만 계획 설명과 경험 지침이 출력 길이 제한을 넘어서 각각1회 갱신이 거절됐습니다. 가상 경험의 실제 LLM 병합에서는2개→1개 통합과 근거·반례·재시작 복원을 확인했으나 장기 지침 품질은 미검증입니다.

다음 검증은 시선 인자 철회와 잦은 이동 전환의 원인, 출력 형식 실패 후 회복, 실제 작업·협동 성과에 집중합니다. 이전 버전의 장시간 실행 결과를 현재 선택 방식의 성능으로 합산하지 않으며, 다른 구현과의 통제된 성능 비교는 수행하지 않았습니다.

재생 도구는 `scripts/context-efficiency-check.ts`와 목적지 선택 비교 스크립트입니다. `scripts/guidebook-maintenance-check.ts`는 가상 경험의 실제 LLM 검증용입니다. 각 도구는 참조 복원과 해당 관측·선택 범위의 보존을 검사하며, 실제 API 호출은 `--with-api`와 비용 설정을 명시해야 합니다. 원본 로그와 운영 기록은 공개하지 않습니다.
