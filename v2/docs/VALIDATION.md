## 현재 병목

**현재 서버 결과.** 채굴 시간을 실행기가 산정하도록 수정한 뒤 두 봇300초 자율 기능검증을 완료했습니다. 이전과 같은 초기 월드·소지품, 낮·자연 스폰 OFF 조건이며 세부 목표나 중간 개입은 없었습니다. Bob은 제작6회, 설치17개(제작대 포함), 판자14개 보관을 수행했습니다. 서버에서도 블록과 상자 내용을 확인했으며, 완성된 거주지로 평가하지 않습니다.

**채굴 유지.** Alice가 석탄 채굴을1회 선택했지만 JEV의 stop으로 취소했습니다. 예상 채굴1.15초·실행 예산3.725초였으나 실제 채굴0.507초에서 중단됐고, 파괴·획득은0입니다. 중단 판단 요청은 접근 단계에서 생성되어 당시 입력에는 채굴 시간 추정이 없었고, 응답 적용 때는 채굴 단계였습니다. 중기 작업도 석탄 획득이 아닌 위치 기록이었습니다. 시간 초과는 아니며 진행 정보 무시나 단일 원인으로 단정하지 않습니다. 별도 통제된 실행기 검증에서는 돌·석탄광석의 파괴와 획득에 성공했습니다.

**계획과 공백.** 보관·제작·제작대 설치 결과를 후속 계획에 반영했지만, 완료 전에 요청된 계획이 뒤늦게 도착해 설치를 다시 제안하는 구간도 있었습니다. 전체 무실행 비율은 Alice43.4%, Bob73.0%(평균58.2%; 이전5분52.99%)였고 명시적 idle 실행은 별도로18.2초·61.1초였습니다. 무실행은 액션 실행 구간 외 시간으로 물리적 정지와 다릅니다. Bob의 look88회 중87회는 보이는 블록 집합이 그대로였습니다. 단일 실행 차이를 일반 성능으로 해석하지 않습니다.

HTTP·입력 한도·계획 길이 오류는0건이었지만 장소 근거 ID 오류5회, 경험 지침 길이 오류1회가 있었습니다. 사망은 없었습니다. 다음 과제는 단계가 바뀐 뒤 도착하는 중단 판단, 계획·즉시 행동의 일관성, 완료 결과와 계획 갱신의 동기화입니다. 강제 반복 금지는 추가하지 않았으며 장기 생존·협동 성능은 미검증입니다.

재생 도구는 `scripts/context-efficiency-check.ts`와 목적지 선택 비교 스크립트입니다. `scripts/guidebook-maintenance-check.ts`는 가상 경험의 실제 LLM 검증용입니다. 각 도구는 참조 복원과 해당 관측·선택 범위의 보존을 검사하며, 실제 API 호출은 `--with-api`와 비용 설정을 명시해야 합니다. 원본 로그와 운영 기록은 공개하지 않습니다.
