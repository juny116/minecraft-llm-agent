## 현재 병목

**이동과 생산적인 행동.** 반경2 완료 기준을 설명·인자 선택·실행에서 통일했습니다. 후속 서버 기능검증은62.2초 동안 이동30회에 성공했지만 입력 한도 오류로 중단했습니다. 이전 실행과 동일한 첫43.5초 비교에서 평균 무실행 비율은92.9%→49.8%였습니다. 무실행은 액션 실행 구간 외 시간이며 명시적인 `idle` 선택과 다릅니다. 왕복 이동과 취소도 있었고 채집·제작·설치는 없었으므로 생산적인 플레이나 장기 안정성을 입증하지는 않습니다.

**입력 크기와 기억.** 일반 지형 누적을 모델 입력에서 제외하고 관측·중요 장소·선택지를 공유 참조로 연결했습니다. 이전 한도 오류18건을 재구성한 요청은 평균73.5KB→28.4KB로 줄었고 현재 관측·중요 장소 보존을 확인했습니다. 대표3건의 실제 JEV 요청은13.8k~16.3k 입력 토큰으로 정상 응답했습니다. 실제 LLM의 가상 경험 지침 병합은 첫 형식 오류를 거절·보존한 뒤 별도 호출에서2개→1개 통합과 근거·반례·재시작 복원을 확인했습니다. 이 구조로 서버를 다시 실행하거나 장기 기억 품질을 검증하지는 않았습니다.

다음 검증은 새 입력 구조의 짧은 서버 확인, 지침집의 장기 정리 품질, 실제 작업·협동 성과에 집중합니다. 이전 버전의 장시간 실행 결과를 현재 선택 방식의 성능으로 합산하지 않으며, 다른 구현과의 통제된 성능 비교는 수행하지 않았습니다.

재생 도구는 `scripts/context-efficiency-check.ts`와 목적지 선택 비교 스크립트입니다. `scripts/guidebook-maintenance-check.ts`는 가상 경험의 실제 LLM 검증용입니다. 각 도구는 참조 복원과 해당 관측·선택 범위의 보존을 검사하며, 실제 API 호출은 `--with-api`와 비용 설정을 명시해야 합니다. 원본 로그와 운영 기록은 공개하지 않습니다.
