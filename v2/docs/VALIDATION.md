## 현재 병목

**행동과 인자의 선택 불일치.** 선택형 `coordinated + proposal`의 최근120초 서버 검증에서는 API 오류가 없어도 평균 무실행 시간이97.39%였고 이동은4회 성공했습니다. `move` 뒤 이미 도착한 좌표를 제안하고 최종 검토에서 철회하는 패턴이 반복됐습니다. 선택된 그룹에 반경 밖 대안도 있어 단순 후보 누락으로 설명되지는 않습니다. 무실행 비율은 액션 실행 구간 외 시간으로, 명시적인 `idle` 선택과 다릅니다.

**이동 규약 정합성.** 액션 수를 늘리지 않고 `move`의 반경2 완료 기준을 설명·선택·실행에서 공유합니다. 이미 도착한 좌표는 지도에 유지하고 새 이동 인자에서만 제외합니다. 같은 실행의12관측을 각2회 재생한 결과, 반경 밖 목적지 확정은 기존2/24, 완료된 인자 제외20/24, 설명까지 통일21/24였습니다. 주된 개선은 인자 도메인 정합성에서 관측됐으며 설명의 추가 효과는 불확실합니다. 후속 서버 기능검증은62.2초 동안 이동30회에 성공했지만 입력 한도 오류로 중단했습니다. 오류 전 동일43.5초 비교에서 평균 무실행 비율은92.9%→49.8%였습니다. 단일 통제 환경의 짧은 결과이며 장기 안정성·생산적인 작업 진행은 아직 미검증입니다.

**입력 크기와 응답 검증.** 지도와 기록 증가로 생긴 입력 한도 오류는 정보를 제거하지 않는 직렬화로 보완했습니다. 이동이 증가한 후속 검증에서는43.5초부터 입력 한도 오류가 다시 발생했습니다. 관측·지도·실행 피드백의 중복 표현과 동일 오류 반복 요청 처리가 남아 있습니다. 계획 설명 길이·근거ID 오류도 남아 있습니다.

다음 검증은 선택 일관성 개선의 재현성, 큰 기억에서의 정보 접근, 복잡한 지형과 실제 협동 성과에 집중합니다. 이전 버전의 장시간 실행 결과를 현재 선택 방식의 성능으로 합산하지 않으며, 다른 구현과의 통제된 성능 비교는 수행하지 않았습니다.

재생 도구는 `scripts/destination-factor-replay.ts`와 `scripts/destination-leaf-replay.ts`입니다. 원본 입력·질문 일치 검사 후 조건을 바꾸며, 실제 API 호출은 `--with-api`와 비용 설정을 명시해야 합니다. 원본 로그와 운영 기록은 공개하지 않습니다.
