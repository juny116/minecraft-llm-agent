## 현재 병목

**현재 서버 결과.** 중기 작업 지침을 구체화하고 항목별 한도를500자로 늘린 버전으로 두 봇이300초 기능검증을 완료했습니다. 같은 초기 월드·소지품에서 자연 스폰 없이 진행했으며 세부 목표나 중간 개입은 없었습니다. 반복 실패·무진행에 따른 조기 종료만 명시적으로 유예하고 시간·비용·체력 제한은 유지했습니다.

**완료와 갱신.** Bob은 상자2개·일반 블록3개를 설치하고 판자14개를 보관했습니다. 서버의 상자 내용과 일치하며, 중기 계획은 보관 성공을 반영해 다음 작업으로 전환했습니다. 다만 상자1개 설치 의도에서2개를 설치한 중복이 있었고, 이후 채집은 성공하지 못했습니다. Alice는 관측 장소를 기억했지만 대기·반복 관찰이 길게 남았습니다. 계획이 갱신된다는 사실만으로 작업이 진전됐다고 평가하지 않습니다.

**남은 병목.** 채굴12회 중11회는 모델이 고른1초 예산이 소진됐고1회는 실패했습니다. 획득 아이템과 파괴 블록은0입니다. `look`108회 중78회는 보이는 블록 집합이 그대로였습니다. 전체 무실행 비율은 Alice58.8%, Bob47.2%였고, 별도로 명시적 idle 실행은75.1초·23.6초였습니다. 무실행은 액션 실행 구간 외 시간으로 물리적 정지와 다릅니다. 기존 실행과 같은 첫42.2초의 평균 무실행은43.5%→46.9%, 첫120초는 별도의 이전 실행56.5%→49.5%로 비교 창에 따라 달라 일반적인 개선을 주장하지 않습니다.

계획 길이·HTTP·입력 한도 오류는0건이었지만 장소 근거 ID 오류로 갱신4회가 거절됐습니다. 낙하 피해가 있었고 사망은 없었습니다. 후속 수정에서 채굴 시간을 모델 인자에서 제거했습니다. 준비된 돌·석탄광석을 나무 곡괭이로 채굴한 실행기 검증은 각각1.158초·2.304초에 파괴되고 조약돌·석탄을 각각1개 획득했습니다. 진행 정보의 JEV 전송은 모의검증했으며 이 수정 후 자율 루프의 성능은 아직 미검증입니다. 다음 과제는 완료 결과가 계획 생성 도중 도착했을 때의 중복 방지, 장소 근거 인용과 완료 뒤 목표 전환입니다. 강제 반복 금지는 추가하지 않았습니다. 낮·자연 스폰 없는 환경의 단일 실행이며 생존·협동 성능 평가는 아닙니다.

재생 도구는 `scripts/context-efficiency-check.ts`와 목적지 선택 비교 스크립트입니다. `scripts/guidebook-maintenance-check.ts`는 가상 경험의 실제 LLM 검증용입니다. 각 도구는 참조 복원과 해당 관측·선택 범위의 보존을 검사하며, 실제 API 호출은 `--with-api`와 비용 설정을 명시해야 합니다. 원본 로그와 운영 기록은 공개하지 않습니다.
