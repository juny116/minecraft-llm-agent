# 철회와 목적지 선택 분리 — MC-056 진단

2026-10-18. 실제 실행에서 저장한 입력으로 JEV API만 재생했다. Minecraft 접속·게임 행동·운영 정책 변경은 없다.

## 비교 방법

두 봇의 저장 관측8개를 고정했다. 각 봇에서 목적지 그룹을 철회한 첫/중간/마지막3개와 그룹을 선택한1개를 사용했다. 실패에 초점을 둔 표본이며 일반 상태의 분포를 대표하지 않는다. 각 입력을 조건별2회, 순서를 번갈아 호출했다(총32회 인자 판단).

- **기존 joint**: 각 그룹/개별 좌표와 철회를 같은 질문에서 경쟁시킨다.
- **separate**: 먼저 해당 도메인에서 선택을 계속할지 철회할지 이진 판단한다. 모델이 계속하기로 선택한 경우에만 그룹/좌표를 고른다. 하위 질문에서도 다시 철회할 수 있다.

선택한 행동 move는 고정한다. 전체 관측·기억·현재 실행·계획과87~800개의 목적지를 유지한다. 그룹 구성·값·순서는 같다. 로컬 코드는 대체 목적지를 고르지 않는다. 전송은 두 조건 모두 같은 무손실 표 형식을 사용한다.

모든 선택 좌표는 원래 도메인에 있었다. separate의 철회2회는 같은 관측에서 반복됐으며, 바인딩 질문이나 대체 행동을 실행하지 않았다.8관측 중6개에서 반경 밖 선택 수가 늘었고2개는 같았다.

**분리 방식은 이 표본에서 인자 완결성과 거리 조건 통과를 개선했다.** 다만 이진 질문 추가로 호출 수와 지연도 늘었다. 이 결과만으로 실제 idle 감소를 주장할 수 없다. 좌표가 도착 반경 밖이라는 사실은 현재 경로·시야 검증 통과, 목표 기여, 실제 이동 성공과 다르다. 저장 입력만으로 과거 전체 경로 인덱스를 재구성해 물리 성공을 판정하지 않았다.

철회가 여러 구체적 선택지와 경쟁하는 표현이 영향을 준다는 가설과 일치하지만, 질문 표현·호출 수·순서도 함께 바뀌었다. 확률 합을 행동 유용성 확률로 해석하거나 JEV 내부 이유를 확정하지 않는다. 행동부터 다시 고르는 전 과정이나 다른 액션은 이번 비교 범위 밖이다.

## 검증·비용·다음 단계

377개 모의검증과 타입 검사 통과. 이진 철회 시 후속 호출 없음, 낮은 신뢰도의 선택 보존, 전체 선택지 보존, 잘못된 응답 거절을 확인했다. API81건 모두 정상 완료, 총 **$0.054219690**. 응답 사용량과 설정 단가 기준이다. 실패 표본과 원본은 비공개로 보존한다.

공개 도구는 scripts/withdrawal-contract.ts와 scripts/withdrawal-replay.ts이며 명시적 --with-api, 저장 입력 경로, 누적 예산 승인을 요구한다. 일반 실행기에는 연결하지 않았다. 첫 검증 기록에는 철회 답을 내부 none 표현으로 변환한 흔적이 있으며, 후속 진단은 복사본을 변환해 원 응답 기록을 보존하도록 보완했다. 판단 결과·비용은 재실행하거나 덮어쓰지 않았다.

다음은 이 계약을 행동 선택부터 실행까지 연결한 짧은 기능검증이다. 최신 상태에서 무효가 된 선택, 목적 없는 왕복, API 대기와 실제 작업 시간을 나눠 비교해야 한다. 동반 플레이 준비 여부는 대화뿐 아니라 호출에 대한 반응·함께 이동·작업 하나를 나누는 행동으로 확인한다. 아직 안정적인 자율 동료나 협동 성능을 입증한 결과는 아니다.
