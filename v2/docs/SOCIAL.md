# 대화와 협력
별도 LLM 판단이 제안·질문·수락·거절·보고·경고·채팅 또는 침묵을 고릅니다. 매 tick 발화하지 않으며 반복 인사·확인 루프를 억제합니다. planner의 say와 실제 social_speech 전송은 다릅니다.

들은 메시지, 자신의 발언, 약속과 행동 근거를 저장합니다. 수락/거절은 들은 메시지를 참조하고 자기 약속 완료에는 성공한 행동 근거가 필요합니다. 들은 주장과 직접 관측을 구분합니다.

give는 상대 방향으로 떨어뜨리기입니다. 타인 인벤토리를 읽지 않습니다. 수령자는 자신의 획득 관측으로 알리고 송신자는 상대 보고로 취급합니다. 재전달을 무조건 반복하지 않습니다.

실제 지시된 상자 전달·제작·결과 발화를 확인했습니다. 후속 대기에서는 침묵했습니다. 이를 상대 확인 발화나 자발적인 역할 분담의 성공으로 해석하지 않습니다.
