# 두 봇 자율 통합 파일럿

15분을 정상 완주했습니다. 세부 목표·역할 분담 없이 새 기억으로 시작했습니다. 일반 지형, Normal/Survival, 자연 스폰 OFF, 낮밤 진행, 각자 빵3개·도구 없음 조건입니다. 초기 배치 이후 관리자 개입은 없었습니다. 두 봇 체력·허기20, 사망0이지만 일반 야생 생존의 증거는 아닙니다.

## 실행과 정체

100ms 실행 상태 표본에서 집계했습니다. 표본 간격은250ms까지 귀속하고 나머지는 미관측으로 두었습니다. 반올림·미관측 때문에 합계는100%와 조금 다릅니다. 실행 중인 작업에는 실패·취소될 작업도 포함됩니다.

|---|---:|---:|
| 실행 중인 액션 없음 | 374초(41.6%) | 418초(46.4%) |
| 명시적 idle 실행 | 64초(7.1%) | 26초(2.9%) |

| 실질 액션 없이 look/idle/공백이 이어진 최장 구간 | 54초 | 511초 |

액션 없음 중 JEV 응답 대기는 각각194초/255초입니다. 나머지를 전부 호출 주기 탓으로 보지는 않습니다. 의도적 대기나 목표 검토가 겹칠 수 있습니다. 서버도 Bob의 위치·인벤토리가 약513초 변하지 않았음을 확인했습니다. 위치 정체만으로 idle을 판정하지 않습니다.

JEV 응답 중앙값265ms, p95 390ms, 최대653ms였습니다. GPT는 중앙값2.26초, p95 3.97초, 최대7.30초였습니다. 호출 주기 단축보다 작업 지속·목표 전환·봇별 무진전 감지가 우선입니다.

## 결과와 남은 문제

- Alice는 자원 확보 목표를 완료하고 기본 도구 목표로 전환했습니다. 나무 곡괭이·도끼를 만들었습니다. 다만 작업대13개를 반복 제작·설치했습니다(서버 블록 비교 확인).
- Bob은 자원 확보 목표 완료 뒤 완료된 목표를 다시 갱신하는 응답을 내면서 다음 목표 적용이 거절되는 사례가 있었습니다. 약10분 뒤 탐색 목표로 전환했지만 둘러보기 반복이 길었습니다. 장기 계획 적용 오류는 전체17건이며 모든 오류가 같은 원인이라고 확정하지 않습니다.
- 실질 액션 성공108건, 실패22건, 무동작 이동 성공0건입니다. 채굴 취소 중 블록을 부수기 전 취소124건, 부순 뒤 취소32건을 별도 집계했습니다. 취소를 채굴 불가능이나 드롭 없음으로 해석하지 않습니다.
- 채팅20건을 서버에서도 확인했습니다. 마지막 작업대 근처 합류는 실제 이동으로 이어졌지만 자원 전달·공동 제작 증거는 없습니다. 중간 약11.5분 동안 대화가 없었습니다.
- 기억 검토 성공20건, 적용 오류10건입니다. 경험 원본은 보존했습니다. 적용 오류는 API 전송 오류와 구분합니다.

## 다음 우선순위

1. 완료 목표의 동일 내용 재확인은 안전하게 처리하고, 부당한 상태 되돌리기는 거절하면서 새 목표 적용을 막지 않도록 검증합니다.
2. JEV가 실제 위험·상황 변화 없이 진행 중인 채굴을 반복 취소하지 않도록 계속 실행 선택과 취소 근거를 점검합니다.
3. 봇별 의미 있는 진전으로 정체를 감지합니다. 다른 봇의 성공이나 look 반복이 한 봇의 장시간 정체를 가리지 않게 합니다.
4. 기존 작업대 기억·재접근과 제작 실패 피드백을 개선하고, 기억 검토 적용 오류를 분류합니다.
5. 수정 후 짧은 재검증에서 자발적 대화·약속 이행·실제 자원 전달을 구분해 평가합니다. 본실험 준비 완료로 간주하지 않습니다.
