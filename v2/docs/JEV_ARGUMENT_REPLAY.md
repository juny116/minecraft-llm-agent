# JEV 인자 미선택 재생과 공백 재검증

2026-10-18. 같은 관측 재생과 동일 시작 월드의 짧은 기능검증이다. 본실험/성능 벤치마크가 아니다. **입력 한도 오류와 정보 전달 누락은 수정했지만, 높은 공백은 해결되지 않았다.**

## 같은 입력으로 확인한 것

| 비교 | 관측 |
|---|---|
| 아이템의 원래 값 문자열 → 사용할 인자라는 설명 | 같은 관측에서 기존 none 3/3, 설명 추가 후 실제 아이템 3/3 |
| 좌표·각도 그룹을 ID로만 설명 | 선택이 개선되지 않거나 악화. 채택하지 않음 |
| 전체 상태를 자체 표 형식으로 표현 | 정보 복원은 가능했지만 선택이 악화. 채택하지 않음 |
| 값 사용 여부를 별도 JEV 질문으로 판단 | 거절이 늘어남. 채택하지 않음 |
| 원래 토큰 초과 입력 → 그룹 표현 정리 + 동일 JSON의 간결한 문자열 표현 | 최종 재생 3/3 정상 응답·좌표 선택 |
| 후반 시선 입력 3개 × 3회 | 기존 각도 그룹 none 9/9. 단위 설명만으로는 1/9 구간 선택. 방향 의미를 갖는 8개 구간은 9/9 구간 선택, 정확한 각도까지는 7/9 완료 |
| 이미 도착한 좌표 선택에 거리 판정 정보 추가 | 같은 입력에서 여전히 3/3 같은 가까운 좌표 선택. 정보 추가만으로 행동이 개선됐다고 주장하지 않음 |

표현·선택지 구성이 결과에 영향을 준 것은 확인했다. 모델 내부의 모든 none 이유를 알아낸 것은 아니다. 소수의 동일 입력 재생이며 일반화 성능을 보장하지 않는다. 실패한 중간 시도와 비용도 비공개 원본에 보존했다.

## 반영한 변경

- 비수치 인자는 설명과 실제 값을 갖는 구조화 선택지로 전달한다. 큰 목록은 최대32개 그룹, 숫자는 기존 범위, 시선 yaw는8개 구간→정확한 각도다. 모든 기존 값에 선택 경로가 있고 none도 유지한다. 로컬 추천 순위·강제 실행·자동 대체는 없다.
- 큰 요청은 동일 JSON의 필드·값·목록·텍스트를 유지한 간결한 문자열로 전달한다. 작은 요청은 기존 객체 표현을 유지한다. 전환 기준28000바이트는 보수적인 전송 표현 선택 기준이지 토큰 상한의 증명이 아니다. HTTP400의 max_tokens_exceeded는 별도 진단 이벤트로 기록한다.
- 카메라 라디안 관측과 도 단위 인자의 관계, 방위·현재 각도를 명시한다.
- 이동 도착 반경2와 이미 도착 범위인 좌표를 알려준다. 그 좌표를 후보에서 제거하지 않으며 선택지에도 거리 판정 사실을 설명한다.
- JEV가 선택한 행동·이미 선택한 인자·미선택 인자·제공된 값 개수를 기록한다. 이 **미실행 결과**를 다음 JEV 및 중기·장기 LLM 입력에 연결한다. 물리적 행동 실패/불가능 증거로 오인하지 않도록 표시한다. 일반 재계획 요청이 직전 구체적 인자 실패를 덮어쓰지 않는다.
- 실제 실행 직전 검증은 유지한다. 목적지가 도착 범위라 움직이지 않을 경우, 일반적인 상태 변경 메시지 대신 구체적인 이유를 반환한다.

구조화 선택지는 [공식 API](https://docs.typesafe.ai/api)와 [구조 설명](https://docs.typesafe.ai/primitives/advanced)이 지원하는 표현이다. 이 지원 사실과 실제 판단 품질은 별개다.

## 서버 검증

같은 기준 월드 복제·같은 인벤토리·새 기억에서 두 봇에게 세부 목표를 주지 않았다. 중간 단계도 실패 기록으로 남겼다.

| 회차 | 시간 | 무실행 비율, 두 봇 평균 | 결과 | 비용 |
|---|---:|---:|---|---:|
| 이전 행동·인자 방식 |89초, 조기 중단|97.82%|이동1, 설치0, HTTP400 13건|$0.3114|
| 표현·직렬화 수정 |120초|98.87%|설치7, HTTP 오류0|$0.4237|
| 시선 의미 보완 |120초|99.81%|설치2, 시선 인자 none 0, HTTP 오류0|$0.3435|
| 미실행 피드백·도착 정보 연결 |120초|95.11%|이동9, 설치4, HTTP 오류0|$0.4618|

시간가중 활동 샘플이다. 순간적인 look은 샘플 사이에 끝날 수 있다. 명시적 idle은 이번 세 회차에서0이었다. 이동·설치 횟수는 작업의 유용함을 보장하지 않는다. 서버에서는 최종 판자4개 소비/설치, 한 봇 약27블록 이동, 다른 봇 약1블록 이동을 확인했다. 설치된 벽은 두 봇 사이 시야를 가렸으며 전달·공동 작업은 없었다. 사망0, 체력·허기 유지. 통제된 낮 환경의 짧은 검사이므로 야생 생존 검증이 아니다.

최종 회차 상세:
- JEV563요청, 평균270ms. LLM65요청, 평균2224ms. 전체 행동·인자 판단 평균639ms, p95 1071ms.
- 감독 응답239회: selected69, continue3, unresolved167. 미해결은 설치 위치56, 목적지48, 재계획63회다.
- 이전 회차에서 도착 범위 좌표가34번 거절된 원인을 찾았다. 최종에서도 명확한 도착 정보를 받은 뒤 같은 종류 선택이30번 남았다. 입력 누락만으로 설명할 수 없다.
- 무실행 시간은 실행 기록 기준 봇당 평균113.867초/120.058초. 이 중 JEV HTTP 대기와 겹친71.732초, 겹치지 않은42.136초다. 겹침 자체를 원인 기여도로 해석하지 않는다. 인자 미선택→다음 판단 대기와 실행 전 거절이 함께 공백을 만든다.
- 중기 LLM46요청 중39개에 실제 미실행 피드백이 들어갔다. 초기에는 전달할 피드백이 없었다. 직렬화한 전체 JEV 상태563건은 추적된 원본 상태와 복원 후 동일함을 확인했다.
- 최종 최대 JEV 입력31366토큰. 이번 재현/실행에서는 초과0건이나, 계속 커지는 지도·대화가 무한히 들어간다는 보장은 없다.
- 중기 LLM의 잘못된 장소 근거 ID1건은 거절됐다. 이 오류를 성공한 장소 갱신으로 처리하지 않았다.

현재 작업의 모든 재생과 실제 E/F/G 검증 합계는 사용량 환산 **$1.3758(JEV $1.0104, LLM $0.3654)**. 앞선89초 회차는 이 합계에서 제외했다. 타입 검사와 전체338개 모의검증 통과. 봇 종료, 추가 실행 없음.

## 남은 작업

1. 행동 종류 선택과 후속 인자 선택의 정합성을 개선해야 한다. 충분한 입력이 있는데도 거절·근거리 목적지를 반복하는 경우를 모델 판단 문제와 실행기 제약으로 구분한다.
2. 다음 비교는 같은 관측에서 인자 선택과 실행 가능성 확인을 함께 제시하는 방식 등으로 한다. 로컬 코드가 행동을 강제하거나 none/좌표를 제거해 공백 수치만 낮추지 않는다.
3. 관측·중요 지도·대화가 더 커지면 모델 주도의 접근/분할 읽기가 필요하다. 현 표현 전환만으로 모든 크기의 입력을 해결했다고 보지 않는다.
4. 장소 근거 ID 오류와 설치로 생긴 시야 차단, 실제 협동 품질도 남는다. 본실험 준비 완료가 아니다.
