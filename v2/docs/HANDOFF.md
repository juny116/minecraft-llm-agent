# 개발 인수인계

- 활성 구현은 `v2/`, A 스킬 기반 액션17종입니다. B 기본 조작 학습 버전은 설계만 있습니다.
- 읽을 순서: 루트 README → SPEC.md → READINESS.md → PILOT.md. 공개 문서는 규약과 검증 범위만 기록합니다.
- 기능 변경 후 README의 검증/TODO를 갱신하고 타입 검사·관련 테스트를 실행하세요. 현재241개 모의검증 통과.
- 최근 변경: 재접속 목적지 기억과 현재 경로 발판 구분, 막힌 경로의 실제 카메라 관찰, 제작대 재조준, 실패 조건 재시도 제한, 계획의 첫 액션 검증, 도착 기준 통일, 무동작 이동 감지.
- 경험 기록은 보존합니다. 파괴·드롭 관찰·인벤토리 획득을 구분하고 취소/시간 초과를 불가능의 증거로 쓰지 않습니다. 저신뢰도 자체로 JEV 행동을 차단하지 않습니다.
- 목표·계획·기억을 분리하고 재접속 때 목표를 재검토합니다. 계획이 현재 시야와 맞지 않으면 목표 검토는 유지하고 해당 후보만 제외해 JEV의 다른 합법 행동 선택과 재계획을 허용합니다.
- 대화는 현재 시야·인벤토리·실행 상태를 받습니다. 동일 상태의 반복 보고는 억제하되 질문 응답·제안·약속은 별도 처리합니다.
- 본실험은 아직 실행하지 않았습니다. 유료/실제 실행에는 현재 사용자 승인 범위와 누적 ledger를 지키세요. 기능 파일럿을 임의 연장하거나 재시작하지 마세요.
- 원본 실행/운영 인수인계는 ignored `runs/private-docs/`에 둡니다. 키·서버·계정·관리자 대화는 공개하지 않습니다. 미확인 사용량은 임의로 0원 처리하지 말고 명시적 보수 정산 절차를 사용합니다. 매 푸시마다 SECURITY.md대로 나가는 이력까지 검사하세요.

5분 기능 파일럿을 완주했고 서버 상태와 대조했습니다. 최신 수치는 PILOT.md를 보세요. 일반 야생 생존이나 자발적 역할 분담을 보장하지 않습니다.

API 오류 복구:120초 기본 대기, 일시 오류1회 재시도, 취소 재시도 금지, 미확인 응답별 상한 비용 차감, 미확인3건 중단. legacy 미확인 비용 정산 증거는 private-docs에 보존합니다.

최신 구조는 CONTROL_LOOP.md를 먼저 읽으세요. 실제 ApiBrain과 CLI 모의 LayeredMockBrain은 독립 감독/중기/장기 루프를 사용합니다. 기존 Brain.choose만 구현한 테스트용 어댑터는 호환 경로를 유지합니다. 새 구조의 통제된 실제 기능검증도 완료했습니다. 병렬 행동/계획/대화, 별명 재접속, 리스폰과 근거리 회수를 확인했고 요청 형식·대화 스키마·사망 인벤토리 순서 버그를 수정했습니다. CONTROL_LOOP.md의 검증 조건과 남은 한계를 확인하세요. 추가 실제 실행은 자동으로 시작하지 않습니다.

회수 후속 변경: recovery.outcome/decisionHistory를 저장하고 물자 부족분 해소 시 resolved로 정리합니다. 결과 변경은 장기 목표 재검토를 요청하며 진행 중인 구버전 계획 응답을 거절합니다. 이 변경은 모의검증과 기존 서버 기록 오프라인 재생만 수행했습니다. 원래 드롭의 출처를 확정하는 기능이 아닙니다.

최신 통합 실행과 우선 TODO는 INTEGRATION.md를 보세요.15분만 실행했고 종료·비용 정산·서버 대조를 완료했습니다. 계측 추가 외에 이번에 드러난 행동 품질 문제는 아직 수정하지 않았습니다.

지속 기록 규칙: ENGINEERING_LOG.md의 MC 이슈 ID를 사용해 문제·원인/가설·시도·검증·한계를 갱신하세요. 신규 개발 전 관련 이슈를 읽고, 완료 보고 전 해당 기록과 README TODO를 업데이트합니다. PORTFOLIO.md는 공개 개요이며 원본 증거 대응은 ignored private-docs에 보존합니다.
