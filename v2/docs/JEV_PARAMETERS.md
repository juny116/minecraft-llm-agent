# JEV의 행동·인자 선택

최신 실제 재검증: [인자 재생·공백 분석](JEV_ARGUMENT_REPLAY.md).338개 모의검증 통과. 토큰 초과 재현은 수정됐지만 최종 공백95.11%로 자율 활동 품질은 미해결이다.

기본 observed 정책에서 ApiBrain/Runtime은 action → 해당 action의 argument를 JEV에 묻는다. 기존 완성 후보를 고르는 planner 정책/테스트 어댑터는 비교·호환용으로 남아 있다. 실제 기본 파일럿은 새 경로를 사용한다.

## 역할
- LLM: 목표, 중기 의도, 대화, 경험과 중요 지도. 중기 응답의 proposals는 비워둔다.
- JEV: 액션 종류, 대상 블록/좌표/적/플레이어, 제작물과 실행 횟수, 설치 아이템/위치, 장비, 음식, 전달/보관 수량·슬롯, 시선, 대기 시간, 채굴 도구/시도 시간을 선택한다.
- 로컬 코드: 관측을 ID/인자 도메인에 연결하고 API 응답 형식을 확인한다. 실행 직전에 상태/시야/수량/충돌을 재검증하며 한 실행기만 동작하게 한다. 실제 이동·타격·인벤토리 클릭은 기존 모터가 처리한다.

기본 JEV 경로에서는 종류별 가까운2개 채굴, 방향별1개 이동, 제작물8개, count=1, LLM 설치 제안 필요 조건을 사용하지 않는다. 목표 소지량 달성 여부로 후보를 없애지도 않는다. 체력6 이하 행동 제한, 위험 시 pickup 차단, 피격 즉시 채굴/수거 취소, 동일 전달30초 금지, 일반 전환3회 확인과 완료 임박 전환 유예도 이 경로에서는 적용하지 않는다. 관련 상태/최근 결과/실패 조건은 입력으로 전달한다. 저신뢰도만으로 행동을 금지하지 않는다. 사망·취소·예산·연결·물리적 실행 검증은 유지한다.

## API와 정보 범위
첫 요청은 행동/계획 검토/대화 라우팅을 함께 묻고, 이후 선택된 행동의 인자를 조건부로 묻는다. 앞선 선택은 boundArguments로 전달한다. 다른 질문의 답을 암묵적으로 공유한다고 가정하지 않는다. 현재 구현의 인자 질문은 순차적이며 독립 질문 배칭은 향후 계측 후 검토한다.

Choice의255개 API 한도 안에서 비수치 목록은32개 이하 그룹, 수치 목록은254개 이하 그룹과 none으로 나눈다. yaw는 의미를 명시한8개 각도 구간을 먼저 고르고 정확한 값을 고른다. 모든 도메인 항목은 선택 경로를 갖고 로컬 상위순위로 제거하지 않는다. 그룹은 입력 순서의 분할이며 추천이 아니다. 그래도 계층적 선택의 오류·그룹 편향은 가능하다. none 또는 빈 도메인은 이유를 기록하고 중기 검토를 요청한다. 임의 fallback 액션은 실행하지 않고 기존 실행은 유지한다.

모델에 전달하는 시야/일반 장소의 추가128개 요약도 제거했다. 시야는 기존 기하학적 샘플링으로 실제 관측한 블록, 일반 기억은 기존 공간 기억 한도 안의 좌표, 중요 지도는 전체다. 전체 Minecraft 세계나 모든 가능한 행동을 표현한다는 뜻은 아니다. 보지 않은 맵/상대 체력/상대 인벤토리는 제공하지 않는다.

동일 관측 스냅샷에서 인자를 선택하고 끝에 현재 상태로 재검증한다. 연결/생명/대상 변화와 취소는 기존 검증을 유지한다. 새 경로의 기본 결정 유효시간은30초(기존 단일 선택5초); 설정된 값은 우선한다. 중간 요청도 각각 API 예산에 계산한다. 여러 요청의 누적시간이므로 실제 지연·공백·비용을 별도 측정해야 한다.

## 실행 계약과 남은 로컬 처리
- 제작1~16은 레시피 실행 횟수, 전달1~64는 아이템 개수다. 채굴 시도1~120초, 대기0.1~10초, 시선은 정수 각도 범위다. 이는 현재 스킬의 수치 인터페이스/작업 상한이며 자유로운 연속 제어가 아니다.
- 설치는 관측한 면에 대해 광선/거리/빈 공간을 확인한 site에서 선택한다. 일반 상자 설치를 지원 재료에 추가했다. 문·침대·유체 등 미지원 설치는 아직 없다.
- 전투는 선택한 적과 현재 손 장비를 사용한다. 다른 장비는 equip으로 선택한다. 공격 거리/쿨다운·짧은 전투 루프·도주 경로는 로컬 모터다.
- 채굴 후 제한된 인근 드롭 수거는 기존 mine 스킬 내부 동작이며, 별도 pickup 액션의 대상은 JEV가 고른다. 경로 탐색/충돌 회피와 이러한 스킬 내부 동작까지 모두 학습 모델로 바꾼 것은 아니다.
- 전달 수령은 상대에게 확인해야 한다. 기억 속 보관함 내용은 현재 재고를 보장하지 않는다. 알려진 장소라도 경로가 없을 수 있다.

## 검증
타입 검사와 전체330개 모의검증 통과. 제한 뒤 대상 선택, 비단위 제작 수량, 제안 없는 설치, 모든 인자 계약,1000개 도메인의 마지막 값 도달, API 다단계 연결, 단일 실행기 전환, 중요 지도 차원 구분, 사라진 적의 자동 대체 거절, 빈 도메인의 무실행을 검증했다. 실제 API/게임 실행은 하지 않았다. 새 구조가 더 유용하거나 빠르다는 성능 주장은 아직 할 수 없다.

다음: 짧은 실제 검증에서 단계별 응답시간·인자 선택 성공률·물리 검증 거절·none 이유·공백과 비용을 측정한다. 임의의 행동 금지 규칙으로 실패를 숨기지 않는다.

100ms 목표 샘플의 시간가중 비율이며 순간 look은 샘플 사이에 끝날 수 있다. 실행 기록으로 계산한 정확한 무실행 구간은 봇당 평균86.749초: JEV HTTP 대기와 겹친47.691초, 겹치지 않은39.058초다. 겹침은 원인 기여도의 증명이 아니다.

- JEV358요청 중345성공/13 HTTP400. 전체 요청 응답 평균272ms; 정상 완료한 행동·인자 판단160회의 전체 지연 평균576ms, p95 1150ms. LLM52요청 평균2021ms. 전반적인 API 지연 폭증이 주원인은 아니다.
- 판단160응답 중130 unresolved: 목적지 none45, 재계획42, 시선 none21, 블록 아이템 none21, 설치 위치 none1.30 selected 중27개 실행 기록(look26, move1). 직접 none 선택이며 신뢰도 임계값으로 막은 것이 아니다. 사용 가능한 블록 아이템이 제시된 상태에서도 none을 골랐다. 정확한 모델 내부 이유는 알 수 없으며 질문 표현·큰 도메인·정보량/선택 일관성은 후속 검증 가설이다.
- 첫400은72.156초에 발생했다. 첫 실패 입력을 서버 접속 없이1회 재전송해 `max_tokens_exceeded` 응답을 확인했다(비용0). 실패 본문 약67KB 중 질문 약35KB, 관측 약18KB, 대화 약8.5KB다. 정상 JEV 응답의 input_tokens 범위8488~25652; 정확한 서비스 상한은 이 기록만으로 확정하지 않는다. 첫400 이전에도 무실행 비율은 각94.78%/99.84%였다. 토큰 초과만으로 전체 공백을 설명할 수 없다.
- 중요 장소 갱신은 잘못된 근거 ID로 중기 응답1건 거절됐다. 근거 검증은 유지한다. 전체 장소 기억의 누락 없는 실제 운용 검증을 통과했다고 보지 않는다.
- 서버 대조: 한 봇 이동1회, 다른 봇 위치 유지; 인벤토리·블록 변화0, 사망0, 대화12건. 협동 생산성/자율 생존 성공이 아니다.
- 비용$0.311363496(JEV $0.231461496, LLM $0.079902). 종료 후 추가 게임 실행 없음. 원본 입력·출력·요청 ID·관리자 대조·진단 응답은 비공개로 보존했다.

후속 우선순위: (1) 중요 지도는 유지하며 입력 중복과 단계별 무관한 큰 필드를 줄이고, 도메인 전체를 선택 가능하게 유지하는 페이지 구조의 실제 토큰 예산을 검사한다. (2) 같은 관측을 재생해 의미 있는 인자 설명/도메인 분할/none 선택의 차이를 소액 비교한다. 강제 행동이나 임의 우선순위로 해결하지 않는다. (3) 실시간 실험 재개 전 한도 초과와 근거 ID 오류를 검증한다. 호출 주기 단축은 현재 첫 해결책이 아니다.


## 선택적 명시적 철회 계약
JEV_ARGUMENT_CONTRACT=explicit은 인자 none을 revise로 바꾸고 선택한 행동/기존 인자를 명시한다. 전체 도메인은 보존하며 철회는 미실행 결과로 기록한다. 기본값은 legacy, 실제 검증에서 공백 개선은 없었다. [120초 결과](JEV_EXPLICIT_LIVE.md)
