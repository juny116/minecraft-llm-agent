# 경험과 가이드라인
runs/memory/experience/<profile hash>/에 memory.json, social.json, spatial.json, goals.json을 저장합니다. namespace·모드·서버·버전·봇으로 분리됩니다. 실제 프로필/로그는 비공개입니다. 월드 초기화 시 namespace를 바꾸세요.

## 경험 → 검토 → 검색
1. 선택, 당시 관측, 실행 결과, 변화와 사용한 지침 버전을 episode로 저장합니다.
2. LLM이 미검토 경험을 읽어 가이드라인을 생성·수정·폐기합니다.
3. 지침에는 적용 조건, 불확실성, 근거·반례 episode ID가 붙습니다.
4. 현재 적 종류·내 장비·체력 조건으로 관련 활성 지침 최대4개를 제공합니다.

보통 미검토 행동4개 또는 실패/확인된 전투 완료에 반응하며 자동 검토는 최소30초 간격입니다. 요청당 다음8개 경험과 관련 기존 지침을 제한해서 제공하며 같은 API 예산을 사용합니다.

가짜 근거, 제공되지 않은 근거, 오래된 동시 수정, 반례의 무단 삭제를 거절하고 개정 이력을 보존합니다. 근거의 의미적 타당성은 여전히 LLM 판단입니다. 검색은 조건 필터이며 임베딩 검색이 아닙니다.

## 저장·한계
임시 파일·원자적 교체·잠금으로 기록합니다. 손상·프로필 불일치는 파일을 보존하고 오류 처리합니다. 전체 JSON 저장 방식이므로 장기 대규모 실행에는 압축/DB가 필요합니다. 저장 실패 시 로그를 확인하세요.

사회적 기억은 SOCIAL.md, 장소 기억은 SPATIAL-MEMORY.md 참고. 다른 봇의 말은 출처 있는 보고이며 직접 확인한 사실과 구분합니다. 자율 목표는 별도 GOALS.md 규약으로 저장·재검토합니다. 경험 지침과 의도를 같은 문서로 합치지 않습니다. 현재 행동 단계는 자동 복원하지 않습니다.


## 검토 적체와 출력 예산

다음 최대128개 원본 경험 구간에서 실질 경험을 최대8개 검토한다. 상태 변화 없는 성공 idle/look는 수량·양끝 표본으로 요약하며 실패는 보존한다. 원본 JSONL은 삭제하지 않는다. 요약이 새 시각 정보 부재를 증명하지 않으며, 인용 근거는 실제 입력한 ID만 허용한다. 반성 출력은 최소2048토큰을 예약하고, 잘림/길이 오류는 다음 검토에 구체적으로 전달한다. 검토 완료 지점은 표본뿐 아니라 요약한 구간 끝을 포함한다.
