# 여러 단계 계획과 후속 보충: idle 계측

2026-10-18. 요청한 두 변경만 구현했다: (1) 관측에 근거한 여러 단계 계획, (2) 실행 중 후속 계획 보충. 후보가 없을 때 즉시 재계획하는 제안3은 보류했다. JEV 호출 주기와 일반 중기 계획 간격은 유지했다. 타입 검사와294개 모의검증은 개발·공개용 체크아웃에서 모두 통과했다.

## 구현

- 중기 계획은3~5단계를 선호하고 최대6단계다. 재료 소비/생산과 선행 단계 성공을 조건으로 계획하되, 모르는 좌표나 억지 대기 단계를 만들지 않는다. 정보가 부족하면 더 짧게 계획한다.
- 남은 단계2개 이하이고 작업이 진행 중이면 `mediumRequest.mode=append`로 후속 단계만 비동기 요청한다. 활성 실행을 교체하지 않고 남은 순서 뒤에 연결한다. 각 단계의 실제 실행은 JEV와 현재 관측 검증이 담당한다.
- 요청은 한 번에 하나이며 보충끼리 최소5초 간격이다. 일반 재계획5초 제한과 분리해 짧은 작업 도중에도 보충을 시작한다. 실행 중 JEV의 일반 검토 요청은 후속 보충으로 처리할 수 있지만 실패/목표 변경 등은 계획 교체 경로를 유지한다.
- 목표·실행 세대·회수 결과가 바뀌면 오래된 응답을 폐기한다. 기존 단계 ID를 반복한 보충은 거절한다. 실제 결과를 예측값으로 덮어쓰지 않는다.

## 실제 검증과 실패한 시도

별도 목표·물자 지급 없이 직전 월드와 기억을 이어서 사용했다. Normal/Survival, 자연 스폰 OFF, 낮·맑음 고정. 각 회차의 원본과 서버 관측을 보존했다. 초기 지형·물자·기억이 같은 대조실험은 아니다.

| 회차 | 시간 | 종료 이유 | 비용 |
|---|---:|---|---:|
| D |112.427초 | 보충도 일반5초 제한에 막힘을 확인해 개발자가 중단 |$0.239963 |
| E |109.316초 | 감독 검토 요청이 보충을 배제함을 확인해 개발자가 중단 |$0.242395 |
| F |222.892초 | Alice의 연속 제작 실패4건 보호장치 |$0.459495 |

D/E의 실제 보충 적용은0건이었다. 코드 연결을 수정한 F는 보충 요청25건 중10건 적용,6건은 실행 결과 변경으로 폐기,9건은 기존 단계 ID 반복으로 거절했다. 적용된10건 중9건은 기존 순서 소진 전,1건은 소진 후였다. 중기 교체 계획58개 중21개가2~3단계였다. 모든 응답이 여러 단계이거나 유효한 보충안은 아니다.

## idle 비교

비교 대상은 수정 전600.113초 회차 C와 수정 후222.892초 회차 F다. 비율은 전체 실행시간 기준이며 인과적 개선율/통계적 성능 향상을 주장하지 않는다.

| 지표 | Alice 이전 → 이후 | Bob 이전 → 이후 |
|---|---:|---:|
| 실행 없음 |50.0% →41.6% |51.0% →29.1% |
| 명시적 idle 실행 |14.0% →11.8% |15.0% →8.9% |
| 실행 없음+idle |64.0% →53.5% |66.0% →38.0% |
| 이동·채굴·제작 등 실행 중 |27.5% →39.5% |27.0% →57.1% |

F의 실행 없음은92.83/64.76초, 그중 JEV pending 겹침은57.85/39.85초다. 명시적 idle은26.34/19.85초, 둘러보기는13.83/9.01초, 실제 작업 실행은87.98/127.38초였다.100ms 표본 간격 중250ms까지만 상태에 귀속했고 약1.53/1.52초는 미계측이다. 응답 대기와 공백의 겹침은 API 속도만의 인과적 손실이 아니다. 긴 실패한 경로 시도도 작업 실행 시간에 포함된다.

## 결과와 남은 문제

F에서 Alice는 실질 행동 성공34건·실패10건, Bob은 성공19건·실패3건을 기록했다. 둘 다 최종 체력/허기20. Alice는 조약돌을 얻고 돌 곡괭이·돌 도끼·상자를 제작했다. Bob은 추가 목재를 얻었다. 둘 사이 채팅은0건이며 공동 작업을 검증한 회차가 아니다.

종료 직전 Alice가 이미 만든 상자를 다시 만들려다 판자3개 부족으로2회 실패했고, 이어 문 제작에서 판자1개 부족으로2회 실패했다. 서로 다른 제작 대상이므로 기존 대상별 재시도 제한을 무시한 것은 아니지만, 부족한 재료를 보충하지 않는 계획 품질 문제가 남았다. 연속 실패 보호장치를 풀어 테스트를 연장하지 않았다. 따라서 **10분 완주·안정성 통과가 아니다.**

총 추가 비용$0.941852(JEV $0.490896, 생성 모델 $0.450956). 이 세 회차는 응답 사용량이 확인된 설정 단가 기반 추정이며 청구서 금액은 아니다. 테스트 후 두 봇을 종료했고 추가 실행은 없다.

다음 판단은 (a) 보충안이 기존 단계를 반복하는 비율, (b) 재료 소비를 반영한 순서 계획과 완료 뒤 같은 물품 재제작, (c) 남은 후보 없는 공백을 구분해 보는 것이다. 제안3은 이 결과를 검토한 뒤 별도 결정한다.
