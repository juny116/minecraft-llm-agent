개인 기능검증 서버 준비
- Minecraft Java 1.21.1, Survival. 사용할 봇 이름 whitelist 등록.
- 접속 주소/포트/인증 방식은 비공개로 공유하고 .env에만 입력.
- offline-mode라면 방화벽/VPN으로 접근 제한, offline UUID 확인.
- 빈 테스트 구역과 필요한 재료·음식 준비. 먹기에는 실제 허기 필요.
- 전투는 준비 신호 후 몬스터1마리만, 시간을 제한해서 진행.
- 관리자 관측은 검증용이며 모델 입력에 주입하지 않음.
- 종료 후 접속 종료·임시 몹/후크 정리·기존 월드/인벤토리 보존 확인.
