# 검증 범위와 다음 단계
타입 검사와179개 모의검증 통과. 모의검증은 서버 물리·모델 품질을 보장하지 않습니다.

| 범위 | 실제 확인 | 한계 |
|---|---|---|
| 블록·자원 | 설치, mine 파괴/드롭/획득, pickup | 자율 건축·장시간 채굴 미검증 |
| 보관·제작·장비 | 상자 왕복, 제작, 머리/손 장비 | 모든 특수 아이템 조합 미검증 |
| 화로 | 설치→재료/연료→출력→회수→채굴 | 일반 화로만 검증; 진행률 필드 후속 수정 별도 미검증 |
| 공간 기억 | 재접속 후 상자 기억·재관측 | 장거리 경로 복원 검증 아님 |
| 생존·전투 | 먹기, 좀비 전투 기능 | 자급·복잡한 지형·다양한 적 미검증 |
| 두 봇 | 전달→제작→근거 있는 결과 발화 | 지시된 fixture; 자발적 협동 증명 아님 |
| 대기 | 빈 계획 처리·반복 호출 감소 | 장기 안정성·성공률 평가 아님 |

실제 검증은 짧게 제한했습니다. 최종 대기 검증의 서버 고빈도 관찰은 늦게 시작되어 앞부분은 접속/채팅 로그와 전후 상태만 대조했습니다. 원본 운영 기록은 비공개입니다.

최신 30초 검증은 실패 행동 없이 종료됐지만, 후속 5분 예정 파일럿은 약189초에 반복 채굴 실패로 종료했습니다. 본실험은 아직 하지 않았고 목표·기간·예산·종료 조건을 별도로 정해야 합니다. 무제한 생존이나 사람 같은 플레이를 주장하지 않습니다. 다음 우선순위는 루트 README TODO가 기준입니다.

새 목표 구조: 근거 검증·보류 보존·손상/동시 쓰기 거절·오래된 응답 거절·재접속 게이트를 모의검증했습니다. 3초 CLI 모의 실행2회에서 두 봇 모두 목표 재검토 후 첫 행동이 발생했습니다. 후속 실제 실행에서 목표 검토36회와 잘못된 완료 조건 응답의 오류 피드백 복구를 확인했습니다. 한국어 보고·채집·제작·장착은 가능하지만, 실패 대상 재선택과 반복 둘러보기, 오래된 설명 정정은 남아 있습니다. PILOT.md 참고.
