# 검증 범위와 다음 단계
현재 타입 검사와241개 모의검증 통과. 아래 기능별 기록은 각 기능검증 시점의 범위입니다. 모의검증은 서버 물리·모델 품질을 보장하지 않습니다.

| 범위 | 실제 확인 | 한계 |
|---|---|---|
| 블록·자원 | 설치, mine 파괴/드롭/획득, pickup | 자율 건축·장시간 채굴 미검증 |
| 보관·제작·장비 | 상자 왕복, 제작, 머리/손 장비 | 모든 특수 아이템 조합 미검증 |
| 화로 | 설치→재료/연료→출력→회수→채굴 | 일반 화로만 검증; 진행률 필드 후속 수정 별도 미검증 |
| 공간 기억 | 재접속 후 상자 기억·재관측 | 장거리 경로 복원 검증 아님 |
| 생존·전투 | 먹기, 좀비 전투 기능 | 자급·복잡한 지형·다양한 적 미검증 |
| 두 봇 | 전달→제작→근거 있는 결과 발화 | 지시된 fixture; 자발적 협동 증명 아님 |
| 대기 | 빈 계획 처리·반복 호출 감소 | 장기 안정성·성공률 평가 아님 |

실제 검증은 짧게 제한했습니다. 최종 대기 검증의 서버 고빈도 관찰은 늦게 시작되어 앞부분은 접속/채팅 로그와 전후 상태만 대조했습니다. 원본 운영 기록은 비공개입니다.

현재 판단: **통제된 기능검증에 사용할 기반은 있지만, 최신 통합 파일럿에서 장시간 정체와 목표 전환 오류가 남았습니다.** [최신 결과](INTEGRATION.md)와 [시행착오 기록](ENGINEERING_LOG.md)을 먼저 확인하세요. 본실험 자체는 실행하지 않았습니다. 초기 월드·인벤토리·기억 조건, 기간·예산, 성공 지표를 정해 별도로 실행해야 합니다.

- 두 봇5분 기능 파일럿 완주, 실질 성공50건·실패17건·무동작 이동0건. 실패는 삭제하지 않고 재계획과 함께 기록했습니다.
- 원목/조약돌 실제 획득, 막대기와 도끼 제작, 장착, 작업대 설치, 한국어 보고를 서버 기록과 대조했습니다.
- 재접속 목표 재검토와 경험 보존, 근거 기반 가이드라인 저장을 확인했습니다. 원본 경험은 보존하고 모델 입력의 중복 관측만 요약합니다.
- 미확인 API 사용량은 보호 종료하며, 명시적 보수 정산 시 전체 예약액을 차감하고 미확인 표시를 유지합니다.

자연 스폰 OFF·초기 음식 제공 조건입니다. 자급 생존, 다양한 적, 장기 안정성, 자발적 역할 분담/전달은 후속 검증 대상입니다. 모델은 여전히 불필요한 채굴이나 비효율적인 계획을 선택할 수 있습니다. 구현 기능과 플레이 품질을 구분하고 [PILOT.md](PILOT.md)의 조건·비용·원본 검토 규칙을 따르세요.
