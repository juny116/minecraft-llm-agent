# 명시적 인자 철회 계약: 실제 120초 기능검증

2026-10-18 · MC-056. 두 봇, 새 기억, 세부 목표 없음. 관리자와 기존 기준 월드의 별도 복사본을 준비했고 Normal/Survival·자연 스폰 OFF·초기 소지품·위치·방향을 맞췄다. 본실험이나 장기 생존 검증이 아니다.

## 변경

JEV_ARGUMENT_CONTRACT=explicit을 추가했다. 행동→인자 구조와 기존 전체 스킬·인자 값·계층 분할은 유지한다. 행동 단계에는 관측된 설치 아이템·설치 위치 수·음식 등 능력 정보를 연결한다. 인자 질문은 선택한 행동과 이미 고른 인자를 명시하고, 모호한 none 대신 “행동 선택으로 돌아가기”인 revise를 제공한다. 철회 시 대체 행동을 로컬에서 고르거나 진행 중 실행을 취소하지 않는다.

기본값은 legacy다. 이번 기능검증에서만 explicit을 켰다. [작은 도메인 재생](JEV_STAGED_COMPLETE.md)의 조합 목록이나 좌표 샘플링을 운영에 넣지 않았다. API 응답 이후 실제 실행기의 최신 상태 검증을 사용했다.

선택 응답은 selected51건, unresolved120건, continue1건이다. selected 중 실행 기록은49건이며 나머지를 성공으로 세지 않는다. unresolved120건은 재계획117·인자 철회1·빈 도메인2건이다.

관리자는 Alice의 판자4개 소모와 설치4개를 대조했다. Bob은 소지품 변화가 없고, 설치 실패 이유는 실행 시점에 대상이 현재 관측되지 않았기 때문이다. 판자는 두 봇 사이의 시야를 가리는 위치에 설치됐다. 채굴·아이템 전달·사망은 없고 둘 다 체력/허기20이었다. 서버 대화는5건이다. 협동 성과로 세지 않는다.

## API 지연과 오류

- 정상 JEV 응답322건: 평균260ms, p95 347ms.
- 정상 LLM 응답63건: 평균2302ms, p95 3102ms.
- JEV HTTP529 오류18건, 과부하 대기 이벤트50건. LLM HTTP 오류는 없었다.
- 첫529는 시작12.879초. 행동 단계 재계획은 Bob7.889초, Alice12.001초부터 나타났다. 제공자 오류만으로 재계획 반복 전체를 설명할 수 없다.
- 무실행 시간 중 selectorPending과 겹친 샘플 시간은 Alice52.944초, Bob52.705초다. 순수 HTTP 지연이나 인과 기여도가 아니며 재시도·여러 인자 호출 등의 시간이 섞인다.
- 중기 계획은 Alice19회·Bob22회 갱신됐다. 계획이 전혀 도착하지 않아서만 생긴 정체는 아니다. 계획 내용이 실행 결정을 얼마나 도왔는지는 별도 문제다.
- decision_error58건은 기존 기록에 오류 이유가 없다. 공급자 오류/대기 이벤트와 함께 발생했지만 개별 요청 연결 없이 모두 모델 판단 오류라고 분류하지 않는다. 별명 근거 검증 오류1건도 있었다.

이번 회차는 제공자 과부하에 노출됐으므로 이전 회차와의 차이를 계약 변경의 인과 효과로 해석할 수 없다. 정상 응답이 빨라도 재계획 선택이 반복됐으며, 호출 주기 단축이 해결책이라는 근거는 없다.
