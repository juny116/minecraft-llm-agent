# 블록 설치
place_block은 소지한 지원 블록1개를 보이는 지지면에 인접한 빈 칸에 놓습니다. 위치·시야·거리·겹침을 검사하고 실제 블록 변화·인벤토리 감소로 검증합니다. place_table은 기존 작업대 편의 스킬입니다.

일반 단일 건축 블록과 화로류를 지원합니다. 문·침대·유체·복잡한 방향/다중 블록 설치는 지원하지 않습니다. 정확한 목록은 src/building.ts가 기준입니다.

철거는 별도 액션이 아니라 mine입니다. 집 목표·도면·역할을 코드로 강제하지 않습니다. 단일 블록 검증은 자율 집짓기 능력의 증거가 아닙니다.
