# JEV 행동·인자 계약 비교

2026-10-18 · MC-056. 저장된 관측에 실제 JEV API를 호출한 비교이며 서버/본실험은 실행하지 않았다. 운영 정책도 변경하지 않았다.

## 2026-10-18 정정

재생 로그에는 실행기용 좌표 인덱스가 빠져 있어 일부 이동을 잘못 거절했다. 당시 시야 좌표만 검증용으로 복원해 아래 A/B 통과율을 정정했다. C에는 잘못된 검증 결과가 이미 입력됐으므로 공정한 효과 비교로 사용할 수 없다. 원본은 보존하며 재호출 없이 재집계했다. [원인·후속 비교](JEV_STAGED_COMPLETE.md)

## 방법

- A 기존: 행동 선택 뒤 인자마다 none 허용.
- B 조건부 바인딩: 인자 none 제거 + “이 행동을 한다면 사용할 값”으로 질문. 행동 단계의 대기·재계획·유지·중단은 그대로다. 빈 도메인은 미완결이고 로컬 대체 행동은 없다.
- C 최종 확인: B의 완성 행동을 JEV에 다시 전달해 execute/revise/wait 선택. 기존 실행기의 동일 스냅샷 검증 결과도 사실로 전달했다. 확인 단계와 검증 피드백의 결합 비교이며 revise 후 재선택 루프는 없다.

직전 회차의 이동/설치/시선 인자 요청별 처음과75% 지점(6관측)을 사용했다. 과거 JEV가 고른 행동만 고정하고 인자는 처음부터 다시 선택했다. 이는 조건부 진단이지 운영 중 로컬 행동 강제가 아니다. 별도로 행동 요청의 처음/25%/50%/75% 지점4관측에서 행동부터 재선택했다. 각 조건3반복, 조건 순서 순환. 총90판단이지만 독립적인90환경은 아니다.

관측·기억·목표·전체 인자 값과 비순위 계층 분할은 유지했다. 완료된 행동을 현재 candidates(snapshot, plan)로 검증했다. 아래 통과는 모델 실행 승인과 스냅샷 검증 통과를 모두 의미한다. 경로 탐색이나 실제 설치 성공, 목표 기여의 증거가 아니다.

## 결과

행동 고정 비교(조건마다18판단):

| 방식 | 인자 완성 | 승인+검증 통과 | look/idle 제외 통과 | 평균 시간 |
|---|---:|---:|---:|---:|
| A 기존 |7/18|7/18|1/18|483ms|
| B 인자 none 제거 |18/18|18/18|12/18|551ms|
| C 최종 확인 |18/18|8/18|2/18|782ms|

설치 통과는1/6→6/6→2/6. B 이동은 정정 후6/6 통과다. 이전의 “이동은 모두 이미 도착한 좌표” 해석은 잘못된 재생 검증에 근거해 철회한다. 시선은 모두6/6 통과하지만 현재 yaw/pitch와 각각1도 미만 차이였다. 새로운 관찰로 세지 않는다. C 수치는 실제 승인 응답을 보존한 기록이며 잘못된 검증 피드백의 영향을 포함한다.

행동부터 재선택(조건마다12판단):

| 방식 | 행동·인자 완성 | 승인+검증 통과 | look/idle 제외 통과 | 평균 시간 |
|---|---:|---:|---:|---:|
| A 기존 |6/12|6/12|3/12|666ms|
| B 인자 none 제거 |9/12|9/12|6/12|645ms|
| C 최종 확인 |10/12|3/12|0/12|858ms|

정정 후 B의 look/idle 제외 통과6건은 설치3건과 이동3건이다. 공통 look3건은 현재 시선과1도 미만 차이였다. 한 관측에서는 행동 단계 재계획이 계속 선택됐다.

C는 잘못된 좌표 검증 피드백을 받았다. 원래 “최종 확인에 이점이 없다”는 결론은 보류한다. 원본 승인 응답과 비용은 보존하지만, A/B와의 공정한 성능 비교로 사용하지 않는다.

- 재생 도구가 undefined 필드와 JSON에서 생략되는 필드를 비교해1건 중단됐다. 전송 JSON 기준 동일성 검사로 수정했다. 완료된18판단은 재호출하지 않았고 중단된 시도의2요청과 비용도 포함했다. HTTP/API 오류가 아니다.
- 가짜 응답으로10관측의 바인딩, action/review 옵션 보존, 빈 도메인의 무호출을 검증했다. 타입 검사·기존338테스트 통과.

- B는 none 제거와 질문 표현 변경을 함께 적용했다. 개선을 none 한 요소만의 인과 효과로 분리하지 않는다.
- **실제 idle/공백은 미측정이다.** 이전 서버 공백95.11%와 이 표의 통과율은 다른 지표다. 상태 변화, 진행 중 재판단, 오래된 응답 처리는 범위 밖이다.
