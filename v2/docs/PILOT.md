# 제한된 두 봇 기능 파일럿

목적은 자기 목표·계획·실패 복구·기억·대화를 확인하는 것입니다. 세부 목표, 직업, 수집량, 제작 순서는 지정하지 않습니다. `GAME_CONTEXT`만 공통으로 주며 `userRequest`는 null입니다. 본실험·비교 평가는 별도로 승인하고 설계합니다.

## 실행 조건
- 일반 지형, Normal/Survival, 초기 소량 음식, 자연 스폰 OFF. 밤에도 적대 몹은 없었습니다. 시야는 조도를 모델링하지 않습니다.
- 재접속 사이 같은 월드·인벤토리·목표·기억을 유지합니다. 관리자 관측은 검증용이며 모델 입력에 넣지 않습니다.
- 동일 봇 중복 실행 금지. 코드 커밋/미커밋 상태·모델·한도·초기/최종 관측을 비공개 실행 폴더에 기록합니다.
- 새 비교 실험에서는 초기 상태와 기억 namespace를 통제해야 합니다. 이어서 실행한 기능 파일럿은 독립 표본이나 성공률 벤치마크가 아닙니다.

`v2/`에서, 실제 서버/API 사용을 승인한 경우에만 실행합니다.

```bash
MEMORY_NAMESPACE=survival-pilot-v1 RUN_SECONDS=30 LLM_MAX_OUTPUT_TOKENS=1536 \
  node --import tsx scripts/survival-pilot.ts --live-functional --with-api
```

짧은 확인 뒤 `RUN_SECONDS=300`으로 최대 5분 검증합니다. 명시적 두 플래그 없이는 실행되지 않습니다. `TRACE_MODEL_INPUTS=1`은 디버깅용 관측 입력을 비공개 로그에 추가합니다. 원본 입력·대화·목표·좌표를 공개하지 마세요.

## 종료와 비용
최대300초·300호출·실행당 추정$0.25와 기존 누적 ledger 한도 중 작은 제한을 적용합니다. 일반 CLI는 누적 ledger를 자동 적용하지 않습니다.

사망/접속 종료, 체력6 이하, 봇별4회 실패·부분 결과·무동작 이동, 2분간 유의미한 성공 또는 전송된 대화 없음에도 중단합니다. 성공적인 실질 행동은 실패 누적을 초기화하지만 둘러보기·idle·변위 없는 이동은 초기화하지 않습니다. 종료 시 즉시 봇을 멈추고 이미 전송한 API만 정산합니다. 요청별 상한을 기록하지 못한 미확인 사용량이나 미정산 호출이 남으면 다음 실행을 차단합니다. 상한을 기록한 미확인 응답은 그 금액 전체를 차감하고 bounded_unknown으로 보존합니다. 자동 재시작으로 시간을 연장하지 않습니다.

응답 누락 회차를 계속 진행해야 한다면, 종료된 회차의 유효한 전체 예약액을 보수적으로 차감하는 명시적 절차가 있습니다. 확인된 사용량과 `bounded_unknown` 상태를 보존하며, 실제 청구액으로 단정하지 않습니다. 진행 중인 회차나 유효하지 않은 상한은 정산하지 못합니다.
```bash
node --import tsx scripts/reconcile-functional-cost.ts --charge-full-reservation <ledger-entry-id>
```
이 명령은 결제가 아니라 한도 계산입니다. 보고서는 확인된 사용량 기반 추정과 보수적 합산액을 구분합니다.

사전 비용 예약 때문에 실제 지출이 상한보다 낮아도 중단될 수 있습니다. 비용은 설정 단가 기반 추정이며 청구서 확정값이 아닙니다.

## 결과 읽기
```bash
node --import tsx scripts/pilot-report.ts runs/<run-directory>
```

이 명령은 이름·대화·좌표 없이 봇별 행동 결과, 무동작 이동, 최소 관측 체력, 목표 검토·계획 오류·발화·기억 갱신 횟수와 비용을 집계합니다.
- 파괴 성공과 아이템 획득을 분리합니다. 획득한 아이템이 특정 드롭에서 왔다는 단정은 하지 않습니다.
- 양의 인벤토리 변화에는 제작도 포함됩니다. 순수 채집량이 아닙니다.
- 이동량은 행동 전후 직선 거리 합이며 실제 보행 거리와 다릅니다.
- 목표 검토 횟수는 목표 완료 횟수가 아닙니다. 완료 주장·근거와 대화 내용은 비공개 원본에서 별도 검토합니다.

## 최근 검증
초기5분 시도는 약189초에 반복 채굴 실패로 끝났습니다. 이후 경로·관측·재계획·제작대 재조준·수거 판정·도착 기준을 수정했습니다. 무동작 이동을 발견한 실행은 수동 중단했고 성공으로 세지 않았습니다.

수정 후 한 실행은 약297초에 비용 사전예약 한도로 종료했습니다. 두 봇의 실질 성공은21/19건, 무동작 이동0, 최소 체력20이었습니다. 원목 획득·작업대·도끼 제작/장착·한국어 보고를 서버 기록과 대조했습니다. 파괴 후 미획득과 경로 실패도 남아 있습니다.

그 뒤5분 실행은 시간 종료로 완주했습니다(관측 기록 약301.7초; 이후 마지막 tick 대기를 남은 시간으로 제한). 총81행동 중 실질 성공50건, 실패17건, 둘러보기/대기14건이었습니다. 무동작 이동0, 두 봇 최소 관측 체력20, 목표 검토75회, 계획 응답 오류0회, 한국어 보고4건을 기록했습니다. 파괴38개와 원목·흙·조약돌의 실제 획득을 구분했고, 막대기→도끼 제작도 관찰했습니다. 비용은 설정 단가로 약$0.23660입니다.

경험은 봇별로 유지되며 한 봇이 근거 있는 가이드라인2개를 저장했습니다. 반례가 없는데 임의로 만들지는 않습니다. 이후 검토에는 같은 행동의 과거 성공/실패도 제한적으로 조회합니다. 후속 재접속 검사 중 외부 API 응답1건의 사용량이 불명확해 보호 종료했고, 그 회차의 예약 한도 전체를 보수적으로 반영했습니다.

마지막30초 재접속 검증은 시간 종료로 정상 완료됐고 사용량 미확인 응답은0건이었습니다. 목표 재검토7회와 저장된 관련 가이드라인의 JEV 입력 전달을 확인했습니다. 최종적으로 각 봇에 활성 가이드라인2개씩 남았습니다. 이 검사 비용은 약$0.02131입니다.

자발적 역할 분담이나 자원 전달, 식량 자급, 적대 몹 생존을 이 파일럿으로 입증하지 않습니다. 구현 완료와 모델의 플레이 품질은 구분합니다.

API 기본 타임아웃은120초이며, 일시적인 전송/타임아웃/429/5xx/응답파싱 오류는500ms 뒤 한 번만 재시도합니다. 취소는 재시도하지 않습니다. 사용량이 불명확한 요청은 요청별 예약액 전체를 차감하며3건이면 중단합니다. 요청 ID·모델·경과 시간·오류 종류·상한 비용은 비공개 api_request 로그에 남기며 응답 본문이나 인증키는 오류 로그에 포함하지 않습니다. 진행 없음 판정에는 최대 두 번의 API 대기 시간에 맞춘 유예를 적용합니다. 비용은 확인분과 미확인 상한 합산을 구분합니다.

## 승인된15분 재실행
120초 API 대기로 약900초를 정상 완주했습니다. API 응답653건 모두 사용량을 확인했고 오류/타임아웃은0건이었습니다. GPT 응답10건이15초를 넘겼고 최장67.3초였습니다. 실제 오류 후 재시도는 이번 회차에서 발생하지 않아 모의검증 근거와 구분합니다.

총191행동 중 실질 성공139건·실패25건·둘러보기/대기27건, 무동작 이동0건입니다. 두 봇 최소 체력20, 한국어 발화 클라이언트 전송47건/서버 확인46건(1건 차이는 미해결), 작업대 설치와 돌 곡괭이 제작을 확인했습니다. 재실행 비용은 설정 단가 추정$0.86440(GPT $0.80115, JEV $0.06326)입니다. 이전 짧은 실패 회차의 확인 비용과 미확인 호출 보수적 상한까지 합쳐$1.17293로 승인 총액$3 이내였습니다.

이 회차는 기존 짧은 실행의 월드·인벤토리·기억을 이어갔고 자연스폰은 꺼져 있었습니다. 장기 목표는 계속 자원 확보에 머물렀으며 자발적 역할 분담이나 실제 전달을 입증하지 않습니다. 계획 응답 오류2건과 기억 정리 적용 오류26건은 API 전송 오류와 별개입니다. 경험 원본은 보존됐으나 검토 대기 경험이 남아 있어 다음 과제는 기억 정리 실패 원인과 처리 속도, 목표 전환, 반복 보고 개선입니다.

현재 구조 변경 이후에는 JEV 감독/중기·장기 분리/메시지 분류/리스폰 처리가 적용됩니다. 첫 사망은 즉시 전체 종료하지 않고 최대30초 리스폰을 기다리며 세션3회 사망에서 중단합니다. 이전 실행 결과는 이전 구조의 근거입니다. 최신 변경은 모의검증만 완료했고 추가 실제 실행은 승인 범위를 확인한 뒤 진행해야 합니다.

통합 파일럿: 기본5분 제한은 유지하며, 별도로 승인된 실행만 `--extended-functional`로 최대30분까지 허용합니다. 실제 길이는 RUN_SECONDS, 추가 비용은 MAX_ESTIMATED_USD(상한2.25달러)와 누적5달러 ledger의 잔액 중 작은 값으로 제한합니다. 사망·반복 실패·무진전 등 기존 종료 조건은 유지합니다.

100ms 간격의 activity_sample은 실행 중인 액션, JEV/중기/장기/대화/기억 호출 대기, 마지막 선택을 기록합니다. 액션 없음·명시적 idle·look·실질 액션을 구분하고, 호출 대기 여부는 겹치는 원인 지표로 집계합니다. 위치 정체만으로 idle이라 단정하지 않습니다.

최신 구조의 자율15분 실행 결과와 idle 계측은 [통합 파일럿](INTEGRATION.md)에 별도 기록했습니다. 위 이전 구조 결과와 구분하세요.
