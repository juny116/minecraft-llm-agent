# 5분 생존 파일럿 — 약189초 조기 종료

목적: 장기 생존 점수보다 자기 목표의 생성·유지·보류·실패 대응과 협력을 관찰합니다. 세부 목표·직업·수집량·제작 순서는 지정하지 않습니다. 두 봇에 공통 GAME_CONTEXT만 주고 userRequest는 null로 시작합니다.

## 시작 전
- 새 목표 JSON 계약과 실제 행동을 짧은 유료 smoke check로 확인. 아래 실패 항목 수정 후 재검증해야 함.
- 개인 서버의 작은 일반 지형, 나무·접근 가능한 자원, 소량의 시작 음식. 기존 평지 fixture와 별도 namespace 사용.
- 처음에는 적대 위협 제한. 현재 스킬로 식량 자급/거친 지형/다양한 적 생존이 보장되지 않음.
- 동일 이름의 봇 중복 접속 금지. 시작 인벤토리·환경 조건을 기록하고 관리자 설정은 모델에 숨은 지식으로 주지 않음.
- 출력 토큰 여유, 실행당 최대300초·공유 호출/비용 한도, 기존 누적 비용 ledger 연결 확인. 일반 CLI만 실행하면 누적 ledger는 자동 적용되지 않음.

## 종료 조건
5분·설정한 비용/호출 한도·사망·심각한 체력 저하·계속되는 무진행/오류 중 먼저 발생한 시점. 기록을 보존하고 봇 접속 종료. 자동 재시도·재시작으로 시간을 연장하지 않습니다. 준비된 scripts/survival-pilot.ts는 최대300초·300호출·실행당 추정0.25달러(설정이 더 작으면 그 값)를 제한하고 기존 누적 ledger를 사용합니다. 체력6 이하, 사망/접속 종료, 봇별4회 실패/부분 결과, 2분간 유의미한 성공 행동 또는 전송된 대화 없음에 종료합니다. 마지막 조건은 진행의 간단한 운영 지표이며 학습/탐색의 가치를 판정하는 척도가 아닙니다. 종료 시 미정산 API 예약이 남으면 ledger를 미확인 상태로 보존하고 다음 실행을 막습니다.

## 관찰 항목
- 목표의 관측 근거, 불필요한 목표 변경과 중복 목표
- 보류한 일을 기억하고 적절히 재개하는지
- 실패 후 방법 변경·도움 요청, 완료 작업 반복 여부
- 대화/약속과 실제 행동의 일치, 상대 보고와 직접 관측 구분
- 행동별 시간·실패·API 비용과 과도한 대기

승인된 실행 시 v2/에서 다음과 같이 시작할 수 있습니다. 아래 명령은 실제 서버·API를 사용하므로 준비/승인 전에 실행하지 않습니다.

```bash
MEMORY_NAMESPACE=survival-pilot-v1 RUN_SECONDS=300 LLM_MAX_OUTPUT_TOKENS=1536 node --import tsx scripts/survival-pilot.ts --live-functional --with-api
```

먼저 RUN_SECONDS=30으로 새 목표 응답 계약을 확인하고 결과를 검토합니다. 시간은 접속 준비 후부터 측정하며 연결 대기는 최대20초입니다.

## 최근 실제 API 검증
일반 지형·Normal·Survival, 자연 스폰 OFF. 세부 목표·역할·제작 순서는 주지 않았고, 재접속 사이 목표·기억·월드·인벤토리를 유지했습니다. 밤에도 적대 몹은 없었으며 시야 모델은 조도 기반 인식을 구현하지 않습니다. 전투 생존 성능 평가가 아닙니다.

이동 수정 과정에서 짧은 검증5회와 최대5분 시도2회를 진행했습니다. 마지막 짧은 검증은 실패 행동 없이 종료됐고, 두 봇이 원목 획득과 나무검 제작을 확인했습니다. 첫 파일럿은 작업대 설치 실패로 약43초에 중단했고, 보이는 면 검사와 지연된 설치 확인을 수정했습니다.

마지막 파일럿:
- 약189초에 반복 실패로 종료. 5분을 채우지 않았으며 자동 연장하지 않았습니다.
- 기존 두 자율 목표는 유지; 중기 단계가 채집·제작·설치·장착으로 바뀌었습니다. 목표 검토36회. 잘못된 완료 조건 응답1회는 오류 피드백 후 복구했습니다.
- 행동73건: 성공62건(둘러보기52, 채굴5, 제작3, 설치1, 장착1), 실패11건. 성공 채굴은 파괴 기준이며 획득과 별개입니다.
- 한 봇은 작업대를 설치하고 원목을 추가 획득했습니다. 다른 봇은 원목·판자 확보 후 나무곡괭이를 제작·장착했습니다. 양쪽 체력·허기는20으로 유지됐습니다.
- 한국어 발화9건은 주로 상태/실패 보고였습니다. 공동 작업 분담이나 상대에게 전달한 자원은 확인되지 않았습니다. 오래된 실패 설명과 최신 관측의 정정은 추가 개선이 필요합니다.
- 최종 실행은 GPT85회/JEV74회, 설정 단가 기준 약0.11642달러. 모든 유료 재검증을 합친 이번 수정 검증 비용은 약0.22488달러. 청구서 확정 금액은 아닙니다.
- 관리자 서버 기록과 최종 인벤토리·설치·이동·발화를 대조해 일치함을 확인했습니다. 원본 기록은 비공개입니다.

## 확인된 수정과 남은 한계
경로 제한을 머리 위 여유 공간이 아닌 실제 착지점에 적용합니다. 진행 방향 바닥을 직접 관측하고, 불완전 경로는 관측한 끝점까지만 이동 후 재탐색합니다. 실패/취소 시 잔여 이동을 정지합니다. 수거는 아이템 높이를 사용합니다. 블록 중심이 가려져도 보이는 면이 있으면 광선으로 확인하며, 작업대 설치는 블록·인벤토리 갱신을 최대1초 기다립니다.

목표 오류는 다음 요청에 전달하고 새 관측 ID를 강조합니다. 낮은 신뢰도로 행동을 차단하지 않으며, 반복 실패 뒤 재계획 대기 중인 행동만 보류합니다. 한국어가 아닌 발화는 한 번 교정하며, 생성 중 실행 상태가 바뀐 발화는 폐기합니다.

남은 우선순위는 상호작용 가능한 표면/접근점 선택, 재계획을 거친 동일 실패 대상의 재시도 억제, 반복 둘러보기의 무진전 감지입니다. 모델이 대상을 다시 관측했다는 이유만으로 이전 접근 실패가 해소되지는 않습니다. 목표/관측 오류를 고쳐 단순히 종료 기준을 느슨하게 하는 대신 짧은 검증부터 반복합니다.
