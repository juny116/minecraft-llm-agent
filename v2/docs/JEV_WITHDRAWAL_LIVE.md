# 철회 분리 실행 연결과 120초 기능검증

2026-10-18 · MC-056. **저장 입력에서의 개선이 실제 공백 감소로 이어지지 않았다.** 본실험이나 인간 동반 플레이 검증은 아니다.

## 실행 구조

`JEV_ARGUMENT_CONTRACT=coordinated`와 `JEV_WITHDRAWAL_MODE=separate`를 함께 설정하면 실제 ApiBrain에서도 각 인자 질문 전에 bind/withdraw 이진 판단을 호출한다. bind 뒤에는 원래 도메인의 그룹/값을 JEV가 선택한다. 하위 단계에서도 철회할 수 있다. 관측·전체 도메인·중요 지도·기억은 유지하며 로컬 대체 행동은 없다. 기존 취소·현재 상태 재검증·공유 비용 제한을 사용한다. 기본 withdrawalMode는 joint이며 비교 경로를 보존한다. 추가 호출 비용과 지연이 있으므로 기본 개선판으로 승격하지 않았다.

재생 도구와 실행기는 같은 `src/withdrawal-contract.ts`를 사용한다. 실제 provider의 저신뢰도 bind/withdraw와 검토 상태 유지까지 모의검증했다. 초기 모의응답이 계층 그룹을 값으로 취급해 실패한 것은 테스트 fixture를 단일 leaf로 명확히 고쳐 해결했고, 기존 계층 도메인 검증은 유지했다. 타입 검사와 378개 테스트 통과.

## 방법과 결과

관리자가 동일 기준 월드를 새로 복사했다. 두 봇의 위치·인벤토리·초기 시선·Normal/Survival·낮/맑음·자연 스폰 OFF를 직전 회차와 맞췄다. 새 기억 namespace, 세부 목표 없이 120.008초 실행 후 정상 종료했다. 회차별 자율 계획과 상태 경로가 달라지므로 반복 통제 실험이나 순수 인과 효과는 아니다.

무실행은 시작~종료 구간에서 action_record 실행 구간 합집합을 제외한 시간이다. 실패·취소도 실행 시간에는 포함하므로 생산성을 별도로 평가한다. look와 명시적 idle을 작업으로 세지 않는다. 이번 명시적 idle 실행은 0이며 “모델이 wait를 선택했다”와 “실행기가 비어 있다”는 다르다.

- Alice 무실행 94.75%, Bob 83.98%. 전체 공백 214.483 bot-seconds 중 감독 판단 대기와 겹친 시간은 170.142초(79.3%). 다단계 선택·검증을 포함하므로 순수 HTTP 병목의 인과 비율은 아니다.
- JEV 개별 응답 중앙값 264.5ms / p95 358ms / 최대580ms. 직전 270/374/502ms와 비슷하다. 전체 감독 판단 중앙값은 Alice 1,226.5ms, Bob 702ms(직전824/774.5ms). 호출 주기만 줄이면 해결된다는 증거가 아니다.
- 이진 gate 309회: bind 211, withdraw 98. 목적지 bind/withdraw 각각63회; blockItem 철회21회도 남았다. 단순 철회 횟수는 줄었지만 전체 미해결 비율은53.7%→55.7%였다. 행동·관측 분포가 달라 횟수만으로 품질 개선을 주장하지 않는다.
- 이미 도착한 좌표8회와 유효하지 않은 설치 인자3회는 실행 전에 거절했다. 실행 중 설치면 가림1회·대상 점유1회, 이동 경로 미발견1회가 기록됐다. 취소 이동2회는 별도 분류다.

## 서버 교차 확인과 준비 수준

서버의 1초 수평 위치 기록에서 Alice 총 이동 약5블록·순변위4.9, Bob 약39블록·순변위9.2·방향 반전6회다. 이동은 작동하지만 지속적인 목적 진전과 같지 않다. 판자5개 소모와 실제 설치5개가 일치했다. 파괴·채집·전달·공동 설치는 없었고 체력/허기20, 사망0이었다. 서버는 실패 시도를 셀 수 없으므로 실패 원인은 클라이언트 관측이다.

대화7건: 탐색 제안 → Alice의 쉼터/보관 공간 제안 → 추가 자원이 필요 없다는 답 → Bob의 정찰 지속 응답. 응답은 연결됐으나 실제 공동 작업은 아니다. 설치 후 Alice의 관측 블록 수가1~2개로 줄고, 이후 같은 방향 보기가 반복됐다. 두 봇 사이 시작 구간이 비어 있다는 서버 결과와 개별 카메라 앞 시야 감소는 서로 다른 측정이다. 장소/시야 의미를 모델이 어떻게 사용했는지는 추가 진단이 필요하다.

**감독하에 짧게 대화·지시를 시험할 수는 있지만 자율 동료 플레이 준비 완료는 아니다.** 이번 회차에는 인간 요청·별명·따라오기·위험 대응을 시험하지 않았다. 기존 개별 기능 통과와 현재 자율 통합 성능을 구분한다.
