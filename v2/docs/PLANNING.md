# 목표·계획·재계획
사용자 목표는 선택적인 실행 중 입력입니다. LLM은 안정적인 longTermGoal과 중기 goal/steps를 함께 생성합니다. 사용자 요청은 목표 목록과 분리된 제약이며, 자율 목표의 이유·근거·보류 상태는 GOALS.md 규약으로 관리합니다.

단계 완료는 action_success, inventory_at_least, food_at_least, near 조건으로 관측에서 판정합니다. 자원 목표는 파괴 대신 인벤토리 조건을 사용합니다. 작업1–6단계, 대기는 빈 단계/생략을 허용합니다.

단계 완료·반복 실패·새 대화·위협·목표 변경·정기 검토가 재계획을 요청합니다. 겹친 요청은 합치고 오래된 응답은 폐기합니다. 무변화 idle은 호출을 잠시 줄이며 상태·대화 변화/위협에는 다시 판단합니다.

action_record는 선택/후보/신뢰도, 실행 전후 관측, 변화와 결과를 묶습니다. 최근12개 상세 기록과 오래된 집계가 계획에 들어갑니다. 로컬 안전 동작은 JEV 선택과 구분합니다. 신뢰도는 행동 금지 기준이 아닙니다.

자율 목표는 저장하되 재접속 시 재검토합니다. 사용자 요청·현재 실행 단계·요약은 세션 상태이며 자동 재생하지 않습니다. 영속 경험은 MEMORY-DESIGN.md 참고.
