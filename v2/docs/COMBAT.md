# 근접 전투와 도주
JEV는 내 체력·허기·장비, 보이는 적 종류·위치, 최근 피격과 경험 지침으로 attack/flee 등을 고릅니다. 상대 체력·공격력·난이도 점수는 제공하지 않습니다.

attack은 로컬 코드가 추적·재접근하고 사거리·시야·무기 쿨다운에 맞춰 공격하는 제한 시간 스킬입니다. 지속 전투는 다음 선택으로 이어집니다. flee는 위협에서 거리를 벌리고 제한된 마지막 관측을 사용할 수 있습니다. 모델이 매 타격을 직접 제어하지 않습니다.

처치는 관측된 사망 이벤트로 확인합니다. 실종·시야 이탈·시간 만료는 처치가 아닙니다. 피격은 내 상태 변화로 남기되 원인을 단정하지 않습니다.

좀비 기능검증은 모든 몬스터·지형의 전투 능력을 보장하지 않습니다. 활 사격·방패 방어는 미구현이며 장착만으로 사용 기능이 생기지 않습니다.
